# awesome-claude-code-skills

The ultimate curated directory of Claude Code skills with rankings, categories, metadata, search, and GitHub Pages.

Goals
- Create the largest curated collection of Claude Code skills.
- Rank skills by usefulness.
- Provide installation, usage, commands, screenshots, and examples.
- Generate documentation automatically from JSON data.
- Support community contributions.

Quick start
1. Edit data/*.json to add skills and categories.
2. Run `python scripts/build-rankings.py` and `python scripts/build-search.py`.
3. Run `python scripts/generate-readme.py` to regenerate README and docs.
4. Deploy `website/` to GitHub Pages.

See CONTRIBUTING.md for contribution guidelines.
